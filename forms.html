HTML Forms

<form>

Definition

The <form> tag creates a form that can be used to collect information from users.

Attributes

Attribute Role
action Specifies where form data is sent.
method Specifies how the form data is sent.

Example (code)

<form action="/submit" method="post">
    ...
</form>

Example (result)

<input>

Definition

The <input> tag creates an input field where users can enter or select information.

Attributes

Attribute Role
type Defines the type of input field.
name Gives the input a name.
placeholder Displays a short hint inside the input.

Example (code)

<input type="text" placeholder="Enter your name">

Example (result)

<button>

Definition

The <button> tag creates a clickable button.

Attributes

Attribute Role
type Defines the type of button.
name Gives the button a name.
value Specifies a value for the button.

Example (code)

<button type="button">Click Me</button>

Example (result)

<label>

Definition

The <label> tag provides a text label for a form control.

Attributes

Attribute Role
for Connects the label to a form input.

Example (code)

<label for="email">Email:</label>
<input type="email" id="email">
