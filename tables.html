HTML Tables

<table>

Definition

The <table> tag creates a table for displaying information in rows and columns.

Attributes

Attribute Role
id Identifies the table.
class Assigns a CSS class.

Example (code)

<table>
    <tr>
        <td>HTML</td>
        <td>Web language</td>
    </tr>
</table>

Example (result)

HTML Web language

<tr>

Definition

The <tr> tag defines a row inside a table.

Attributes

Attribute Role
id Identifies the table row.
class Assigns a CSS class to the row.

Example (code)

<tr>
    <td>HTML</td>
    <td>CSS</td>
</tr>

Example (result)

HTML CSS

<th>

Definition

The <th> tag defines a header cell in a table.

Attributes

Attribute Role
colspan Specifies how many columns the cell spans.
rowspan Specifies how many rows the cell spans.

Example (code)

<table>
    <tr>
        <th>Name</th>
        <th>Age</th>
    </tr>
</table>

Example (result)

Name Age

<td>

Definition

The <td> tag defines a normal data cell in a table.

Attributes

Attribute Role
colspan Specifies how many columns the cell spans.
rowspan Specifies how many rows the cell spans.

Example (code)

<td>John</td>

Example (result)

John
