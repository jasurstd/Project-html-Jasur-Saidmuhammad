Semantic HTML Tags

<header>

Definition

The <header> tag defines the introductory content of a page or section.

Attributes

Attribute Role
id Identifies the header.
class Assigns a CSS class.

Example (code)

<header>
    <h1>My Website</h1>
</header>

Example (result)

My Website

<nav>

Definition

The <nav> tag defines a section containing navigation links.

Attributes

Attribute Role
id Identifies the navigation section.
class Assigns a CSS class.

Example (code)

<nav>
    <a href="index.html">Home</a>
    <a href="text.html">Text</a>
</nav>

Example (result)

Home Text

<section>

Definition

The <section> tag defines a separate section of related content on a web page.

Attributes

Attribute Role
id Identifies the section.
class Assigns a CSS class.

Example (code)

<section>
    <h2>About Us</h2>
    <p>This is a section.</p>
</section>

Example (result)

About Us

This is a section.
