Text Formatting Tags

<h1>

Definition

The <h1> tag defines the main and most important heading of a page.

Attributes

Attribute Role
id Gives the heading a unique identifier.
class Assigns a CSS class to the heading.

Example (code)

<h1>Welcome to my website</h1>

Example (result)

Welcome to my website

<p>

Definition

The <p> tag defines a paragraph of text.

Attributes

Attribute Role
id Gives the paragraph a unique identifier.
class Assigns a CSS class to the paragraph.

Example (code)

<p>HTML is used to create web pages.</p>

Example (result)

HTML is used to create web pages.

<strong>

Definition

The <strong> tag indicates that the text has strong importance. Browsers normally display it in bold.

Attributes

Attribute Role
id Identifies the element.
class Assigns a CSS class.

Example (code)

<strong>Important text</strong>

Example (result)

Important text

<em>

Definition

The <em> tag gives emphasis to text. Browsers normally display it in italic style.

Attributes

Attribute Role
id Identifies the element.
class Assigns a CSS class.

Example (code)

<em>Important idea</em>

Example (result)

Important idea
