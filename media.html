Multimedia Tags

<video>

Definition

The <video> tag is used to display video content on a web page.

Attributes

Attribute Role
src Specifies the video file.
controls Displays video controls.
width Sets the video width.

Example (code)

<video src="images/video.mp4" controls width="400">
</video>

Example (result)

<audio>

Definition

The <audio> tag is used to play audio files on a web page.

Attributes

Attribute Role
src Specifies the audio file.
controls Displays audio controls.
autoplay Attempts to play the audio automatically.

Example (code)

<audio src="images/audio.mp3" controls>
</audio>

Example (result)

<source>

Definition

The <source> tag specifies different media files for elements such as video and audio.

Attributes

Attribute Role
src Specifies the media file.
type Specifies the media type.

Example (code)

<video controls>
    <source src="images/video.mp4" type="video/mp4">
</video>

Example (result)

The browser selects the compatible video source.
