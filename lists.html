HTML Lists

<ul>

Definition

The <ul> tag creates an unordered list. Items normally appear with bullet points.

Attributes

Attribute Role
id Identifies the list.
class Assigns a CSS class to the list.

Example (code)

<ul>
    <li>HTML</li>
    <li>CSS</li>
    <li>JavaScript</li>
</ul>

Example (result)

  • HTML
  • CSS
  • JavaScript

<ol>

Definition

The <ol> tag creates an ordered list. Items normally appear with numbers.

Attributes

Attribute Role
start Defines the starting number of the list.
type Defines the numbering style.

Example (code)

<ol>
    <li>Open VS Code</li>
    <li>Create HTML file</li>
    <li>Run the page</li>
</ol>

Example (result)

  1. Open VS Code
  2. Create HTML file
  3. Run the page

<li>

Definition

The <li> tag defines an individual item inside an ordered or unordered list.

Attributes

Attribute Role
value Sets the number of an item in an ordered list.
class Assigns a CSS class to the item.

Example (code)

<ul>
    <li>Apple</li>
    <li>Banana</li>
</ul>

Example (result)

  • Apple
  • Banana
