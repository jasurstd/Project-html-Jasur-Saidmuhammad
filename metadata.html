Metadata Tags

<title>

Definition

The <title> tag defines the title of an HTML document. The title normally appears in the browser tab.

Attributes

Attribute Role
None The title tag does not have common attributes.

Example (code)

<title>My Website</title>

Example (result)

The browser tab displays: My Website

<meta>

Definition

The <meta> tag provides information about an HTML document, such as character encoding and viewport settings.

Attributes

Attribute Role
charset Defines the character encoding.
name Defines the name of metadata.
content Defines the value of the metadata.

Example (code)

<meta charset="UTF-8">

Example (result)

The page uses UTF-8 character encoding.

<link>

Definition

The <link> tag connects an HTML document to an external resource, such as a CSS stylesheet.

Attributes

Attribute Role
rel Defines the relationship between the documents.
href Specifies the location of the external resource.

Example (code)

<link rel="stylesheet" href="css/style.css">

Example (result)

This page is connected to an external CSS file.
