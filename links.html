Links and Images

<a>

Definition

The <a> tag creates a hyperlink that can connect one page to another page or website.

Attributes

Attribute Role
href Specifies the destination of the link.
target Specifies where the linked page opens.

Example (code)

<a href="https://www.google.com">Google</a>

Example (result)

Google

<img>

Definition

The <img> tag displays an image on a web page.

Attributes

Attribute Role
src Specifies the location of the image.
alt Provides alternative text for the image.
width Specifies the width of the image.

Example (code)

<img src="images/example.jpg" alt="Example image" width="200">

<br>

Definition

The <br> tag creates a line break in text.

Attributes

Attribute Role
None The br tag normally does not require attributes.

Example (code)

Hello<br>World

Hello
